# 여행어 (travel_lang)

여행에서 바로 써먹는 회화를 배우는 듀오링고 스타일 언어 학습 앱입니다.

## 주요 기능

- 코스 선택 (일본어 / 영어, 스페인어는 준비 중)
- 유닛과 레슨으로 구성된 스킬트리 학습 경로
- 객관식 & 단어 배열(word bank) 문제
- 하트(생명), XP, 연속 학습일(streak) 시스템
- 진행 상황 로컬 저장 (localStorage)

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 프로덕션 빌드
npm run lint     # oxlint
```

## 기술 스택

React + TypeScript + Vite, React Router, Tailwind CSS v4
